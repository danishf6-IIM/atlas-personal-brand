# Atlas Personal Brand

A responsive personal branding website built with Next.js 15, TypeScript, and CSS.

## Run locally

Install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Personalize your website

Edit `content/site.ts` to replace the sample name, email, social URLs, experience, case studies, certification entries and blog posts. These are placeholders, not verified accomplishments. The contact button opens your email program using `mailto:`—it does not submit to a backend.

## Production build

```bash
npm run build
npm run start
```

## Deploy with Vercel

Import this GitHub repository into Vercel. Select Next.js and the repository root directory. Pushes to `main` will automatically create production deployments after the integration is configured.
